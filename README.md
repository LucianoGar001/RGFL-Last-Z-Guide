# RGFL — Last Z Field Manual

Mobile-first strategy manual for the RGFL alliance.

## Current guides
- Alliance Duel
- Server War / SvS
- Zombie Siege
- Zombie Tyrant
- Tank Fast Travel
- Apocalypse Time

## How the site grows
Every new guide only needs:
1. One optimized image in `assets/web/`.
2. One entry in `guides.json` with title, category and key information.

The homepage, search, filters and full-image viewer update automatically from the guide catalog.

## Publishing
This repository is designed for GitHub Pages. After the image assets are uploaded, enable Pages from **Settings → Pages → Deploy from a branch → main / root**.
